# Data

This directory contains the Mapping Museums data used in data analysis.

Other data files required to run the data analysis script:
* Rural/urban classifications:
    * The official 2021 [England & Wales rural/urban classifications](https://geoportal.statistics.gov.uk/datasets/9dbf7613cbb147b8bb8627ddb3568cff_0/explore)
    * The official 2022 [Scotland rural/urban classifications](https://www.gov.scot/publications/scottish-government-urban-rural-classification-2022/documents/)
    * The official 2015 [Northern Ireland rural/urban classifications](https://www.nisra.gov.uk/publications/settlement-2015-documentation)
    * The [MySociety UK-wide aggregated rural/urban classifications](https://github.com/mysociety/uk_ruc)
* Population data:
    * Mid-2022 population estimates for English and Welsh LSOAs, [ONS](https://www.ons.gov.uk/peoplepopulationandcommunity/populationandmigration/populationestimates/datasets/lowersuperoutputareamidyearpopulationestimates)
    * Scottish population figures are in the Scottish datazone centroids file (see below)
    * Mid-2022 population estimates for Northern Irish Data zones, [NISRA](https://www.nisra.gov.uk/publications/2022-mid-year-population-estimates-small-geographical-areas)
    * Mid-2022 population estimates for Northern Irish Super Data zones, [NISRA](https://www.nisra.gov.uk/publications/2022-mid-year-population-estimates-small-geographical-areas)
* Shapefiles (These must be unzipped before use):
    * Digital vector boundaries for English and Welsh LSOAS, [ONS](https://geoportal.statistics.gov.uk/datasets/ons::lower-layer-super-output-areas-december-2021-boundaries-ew-bsc-v4-2/about)
    * Population weighted centroids for English and Welsh LSOAs, [ONS](https://www.data.gov.uk/dataset/1b61943c-f5e1-4398-babe-5c487257864e/lower-layer-super-output-areas-december-2021-ew-population-weighted-centroids)
    * Digital vector boundaries for Scottish Datazones, [Spatialdata.gov.scot](https://spatialdata.gov.scot/geonetwork/srv/api/records/f6656adf-b720-4612-ad5c-1d13eae94c8b?language=all)
    * Population weighted centroids for Scottish Datazones [Spatialdata.gov.scot](https://www.data.gov.uk/dataset/d5b6fbc1-8a79-46c6-ac64-2de60c6fcb70/data-zone-centroids-2022)
    * Digital vector boundaries for Northern Ireland Super Ouptut Areas, [NISRA](https://www.nisra.gov.uk/publications/super-output-area-boundaries-gis-format)
    * Population weighted centroids for Northern Irish Datazones, [NISRA](https://www.nisra.gov.uk/publications/census-2021-population-weighted-centroids-data-zones-and-super-data-zones)
    * The spatial signatures digital vector boundaries for Great Britain (not included in this repository as it is a very large file), [CDRC](https://data.cdrc.ac.uk/dataset/spatial-signatures-great-britain)
    * Digital vector boundaries of the regions of England, [ONS](https://geoportal.statistics.gov.uk/datasets/f181d27b5bac477388ce81ad935a1227_0/explore?location=52.723884%2C-2.489483%2C7.56)
