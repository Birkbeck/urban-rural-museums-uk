# Urban and Rural Museums

This repository contains R code for the analysis of UK museums in urban and rural areas.

To run the data analysis yourself:
* Download the required data files in `data/README.md` and save them in the `data` directory.
* Open `urban-rural-museums.rmd` in RStudio and press the `knit` button.
* The output file `urban-rural-museums.html` will be updated and figures and tables will be saved as `.png` and `.xlsx` files in the `figures` directory.
