# Urban–Rural Museum Classification Data

This folder contains derived datasets used in the analysis of the urban–rural geography of museums in the United Kingdom. The files link individual museums to urban–rural categories and provide aggregated statistics used in figures and tables in the associated publication.

## Files

### `museums-with-urban-rural-categories.xlsx`

This file contains museum-level data with assigned urban–rural classifications.

Each row represents a single museum site and includes:
- Museum identifier and basic descriptive fields
- Geographic identifiers (small-area units)
- Urban–rural classifications derived from official national schemes
- Harmonised UK-wide urban–rural categories used for comparative analysis

This file is intended for reuse, further analysis, and replication of the study’s results.

### `museums-urban-rural-stats.xlsx`

This file contains aggregated statistics derived from the museum-level data.

It includes:
- Counts of museums by urban–rural category
- Per-capita museum figures
- Breakdowns by country, region, and classification scheme
- Summary tables used directly in the paper and supplementary materials

This file is intended primarily for reference, validation, and inspection of reported results.

## Notes on methodology

Urban–rural categories are based on official classifications produced by UK national statistical agencies and harmonised to enable UK-wide comparison. Details of the classification schemes, harmonisation process, and limitations are documented in the associated paper and main repository README.
